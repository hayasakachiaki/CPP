Fixed

コピーコンストラクタ
コンストラクタに同じクラスの型を参照型で受け取ることで今いるインスタンスのメンバ変数を参照型のメンバ変数で初期化できる

演算子オーバーロード
Fixed& Fixed::operator=(const Fixed& other)

例えばcoutは以下のようなオーバーロード演算子によって成り立っている

std::ostream& operator<<(std::ostream& os, const char* s);

cout << "Hello, World!";
この際operator<<(cout, "Hello, World!"); のようになる

coutは出力バッファに接続され そのバッファに"Hello, World!"を追加する

このようなオーバーロードと呼ばれる設定を自分で適宜追加できる
この際coutはostream& osとして参照型で引き渡される つまり
cout << "Hello, world!" << endl; これは複数のcoutを作成しているわけではなく参照型のcoutを引き継いで使う
そのため自分でオーバーロードを作成する際も参照型で受け取り参照型で返すことを意識する必要がある

演算子の=に新しく機能を追加したい時に上のように条件を追加し 仕様を設定できる
今回はthisが受け取ったFixedと同アドレス出ない場合に代入し *thisを返す
thisはポインタのため*thisを返す必要がある
今回の=はオーバーロードを作らずとも変数ポインタがなくローカル変数だからOK

deepcopy
しかし変数ポインタやnewなどで作られたものがクラス内にある場合 それらを共有してしまうと独立したクラス同士ではなくなってしまう
そのため深いコピーを行う必要があるためオーバーロードの設定が必要
